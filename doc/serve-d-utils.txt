==============================================================================
OVERVIEW                                                *serve_d_utils_overview*

This plugin provides a thin wrapper around various custom requests and
notifications provided by serve-d.

==============================================================================
FUNCTIONS                                              *serve_d_utils_functions*

There are a few helper functions in `ServeD` to simplify finding the client
and working with errors.

`ServeD.new` is the main function which locates the client and returns a new
`ServeD` object on which all methods will be called.

See |serve_d_utils.new| and |serve_d_utils_methods|


------------------------------------------------------------------------------
ServeD.new(opts)                                             *serve_d_utils.new*


    Creates a new ServeD object.

    Parameters:
        {opts} (table) Options for the ServeD instance. Available keys:
            - `client` (vim.lsp.Client): Use a specific serve-d client.
            - `timeout` (integer): Timeout for requests.
            - `quiet_error` (boolean): If true, returns `nil` if no client is
              found.

    Returns:
        (ServeD|nil) The created ServeD instance or nil if the client was not
        found.

------------------------------------------------------------------------------
ServeD.errCodeToStr(code)                           *serve_d_utils.errCodeToStr*

    Converts an LSP error code to a human-readable string.

    Parameters:
        {code} (integer): The error code to convert.

    Returns:
        (string) The string representation of the error code.

------------------------------------------------------------------------------
ServeD.unwrap(e, default)                                 *serve_d_utils.unwrap*

    Unwraps an `ErrorOr<T>` object.

    Parameters:
        {e} (ErrorOr<T>): The object to unwrap.
        {default} (T|vim.NIL): The default value if an error occurs.

    Returns:
        (T) The unwrapped value or the default if there was an error.
